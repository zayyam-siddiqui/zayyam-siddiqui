## 🧭 How I Work

1. **Understand the problem:** talk to stakeholders, find what actually hurts, and turn it into clear requirements.
2. **Design for the real constraints:** data model, APIs, security and cost. Example: when a budget limit hit mid-project, I migrated the AI stack from OpenAI to Groq + Gemini, including an embedding-dimension database migration.
3. **Build and integrate:** connect the product to the tools customers already use (WhatsApp, Gmail, Stripe, ERP systems) with secure webhooks (HMAC), OAuth2 and multi-tenant isolation.
4. **Ship, debug, support:** automated and manual testing (Playwright, API/DB tests), root cause analysis, and iteration after release.
5. **Use AI as a tool, not a crutch:** AI-assisted development (Claude Code, Codex, Gemini) with my own review, ownership and understanding of every line.
